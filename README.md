# mAnimalRewinder 🐾
A lightweight Minecraft plugin that allows players to "rewind" adult animals back into their baby forms.

## ✨ Features
* **Age Rewind:** Transform adult animals into babies with a simple interaction.
* **Loot Drops:** Receive specific items (loot) when an animal is transformed.
* **Fire Drops:** Chance to receive cooked items if the transformation occurs under specific conditions.
* **Configurable:** Fully customize messages, sounds, particles, and drop rates.
* **Update Checker:** Automatically notifies you when a new version is available.

## 🛠 Commands & Permissions
| Command | Description | Permission |
| :--- | :--- | :--- |
| `/manimalrewinder reload` | Reloads the configuration and messages | `manimalrewinder.reload` |

## ⚙️ Configuration
You can customize the plugin behavior in the `config.yml` file:
* **Sounds:** Customize the `already_baby` and `transformed` audio effects.
* **Particles:** Change the visual effects for successful transformations.
* **Drops:** Define which items drop from each animal type.

## 📥 Installation
1. Download the latest `.jar` file.
2. Place it in your server's `plugins/` folder.
3. Restart your server or use a plugin manager to load it.
4. Configure the settings in `plugins/mAnimalRewinder/config.yml`.
